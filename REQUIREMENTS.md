## 🚀 Installation Guide

### Option 1: Using pip
```bash
# Create virtual environment
python -m venv quant_research_env

# Activate environment
# Windows:
quant_research_env\Scripts\activate
# macOS/Linux:
source quant_research_env/bin/activate

# Install dependencies
pip install -r requirements.txt
```

### Option 2: Using conda
```bash
# Create conda environment
conda create -n quant_research python=3.9

# Activate environment
conda activate quant_research

# Install packages
conda install pandas numpy scipy scikit-learn matplotlib seaborn jupyter
conda install -c conda-forge lightgbm optuna
pip install torch torchvision
```

### Option 3: Docker (Recommended for reproducibility)
```dockerfile
FROM python:3.9-slim

WORKDIR /app

COPY requirements.txt .
RUN pip install -r requirements.txt

COPY . .

EXPOSE 8888
CMD ["jupyter", "lab", "--ip=0.0.0.0", "--port=8888", "--no-browser", "--allow-root"]
```

## 📁 Data Setup

### Required Data Structure
```
data/
├── raw/
│   ├── datamin2/          # Minute-level OHLCV data
│   ├── datamin3/          # Additional minute data
│   └── datamin4/
│       └── data_barra/    # Barra factor data
└── processed/             # Will be generated by notebooks
```

### Data Format Requirements
- **Minute Data**: CSV files with columns: datetime, order_book_id, open, high, low, close, volume, money
- **Barra Data**: CSV files with columns: order_book_id, size, [other factors]
- **Date Format**: YYYY-MM-DD for daily data, YYYY-MM-DD HH:MM:SS for minute data

## 🐛 Troubleshooting

### Common Issues

**Memory Errors**
```bash
# Increase Jupyter memory limit
jupyter notebook --NotebookApp.max_buffer_size=1000000000
```

**CUDA Issues**
```bash
# Check GPU availability
nvidia-smi

# Install CPU-only PyTorch if no GPU
pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu
```

**Package Conflicts**
```bash
# Create fresh environment
conda create -n quant_research_new python=3.9
conda activate quant_research_new
pip install -r requirements.txt
```
