# Processed Data Directory

This directory contains processed and engineered features from the raw data.

## File Structure

The following files are generated by `Data Preparation.ipynb`:

- `daily_ret_data.csv` - Daily return rates for all stocks
- `daily_turnover_data.csv` - Daily turnover rates
- `daily_money_data.csv` - Daily trading volume/money
- `vwap_daily_data.csv` - Volume-Weighted Average Price
- `vwap1pct_daily_data.csv` - VWAP daily returns
- `daily_close_data.csv` - Daily closing prices
- `barra_size_data.csv` - Barra size factor (if available)

## Data Format

All files are in wide format (dates × stocks):
- Rows: Trading dates
- Columns: Stock IDs
- Values: Corresponding metrics

## Sample Data

Due to file size limitations, only sample data is included in this repository.
Full data files are generated when running the notebooks locally.

## Usage

These files are used as input for:
1. `Alpha_Factor_Generation.ipynb` - Factor generation
2. `Alpha_Factor_Selection.ipynb` - Feature selection
3. `ML_Model.ipynb` - Model training
